# 设计令牌（Design Tokens）

> 本文件定义项目统一的视觉规范，所有页面代码必须遵循。禁止使用截图或外部代码中的随意色值。

---

## 1. 颜色

### 主题色（Primary）

| 用途 | 色值      | 说明                         |
|------|-----------|------------------------------|
| 主色 | `#496CFF` | 主按钮、链接、选中态、强调色 |

### 文字色（Text）

| 用途        | 色值      | 说明                                         |
|-------------|-----------|----------------------------------------------|
| 主文字      | `#12152e` | 标题、正文、重要信息                         |
| 次要文字    | `#676e93` | 描述、辅助说明、次要按钮文字、菜单项、面包屑 |
| 占位符/禁用 | `#9da5c0` | placeholder、禁用态文字                      |

### 背景色（Background）

| 用途        | 色值      | 说明                                 |
|-------------|-----------|--------------------------------------|
| 输入框/表头 | `#f8f9fd` | Input、Select、Segmented、Table 表头 |
| 内容区背景  | `#f8fafc` | 布局内容区域                         |
| 白色        | `#fff`    | 卡片、弹窗、Segmented 选中项         |

### 边框色（Border）

| 用途   | 色值      | 说明                      |
|--------|-----------|---------------------------|
| 主边框 | `#e8ebf5` | Input、Select、Table 边框 |
| 轻边框 | `#eef2f7` | 侧边栏、Header 分割       |

### 状态色（Status）

| 状态      | 文字/图标色 | 背景色    | 边框色    |
|-----------|-------------|-----------|-----------|
| 成功      | `#52c41a`   | `#f6ffed` | `#b7eb8f` |
| 警告      | `#fa8c16`   | `#fff7e6` | `#ffd591` |
| 错误      | `#ff4d4f`   | `#fff2f0` | `#ffccc7` |
| 信息      | `#1677ff`   | `#e6f4ff` | `#4096ff` |
| 默认/等待 | `#676e93`   | `#f8f9fd` | `#e8ebf5` |

### 禁止使用的色值

以下色值**禁止出现**在代码中，必须替换为上方规范色值：

| 禁止                         | 替换为                 | 原因         |
|------------------------------|------------------------|--------------|
| `#999`, `#666`               | `#676e93` 或 `#9da5c0` | 非规范灰色   |
| `#333`, `#222`               | `#12152e`              | 非规范深色   |
| `#f5f5f5`, `#fafafa`         | `#f8f9fd`              | 非规范背景灰 |
| `#e8e8e8`, `#d9d9d9`（边框） | `#e8ebf5`              | 非规范边框色 |
| `#1890ff`                    | `#496CFF`              | 非规范蓝色   |

## 2. 字体

| 属性     | 值                                                                                  | 说明                         |
|----------|-------------------------------------------------------------------------------------|------------------------------|
| 字体族   | `"PingFang SC", "Microsoft YaHei", system-ui, Avenir, Helvetica, Arial, sans-serif` | 全局统一                     |
| 基础字号 | `12px`                                                                              | 全局默认，一般不需要额外设置 |
| 行高     | `1.5`                                                                               | 全局默认                     |
| 标题字号 | `14px`                                                                              | 页面标题、弹窗标题           |
| 大标题   | `16px`                                                                              | 仅用于极少数场景             |

**规则：**
- 默认 12px，不需要写 font-size
- 禁止使用9px，11px，13px，15px等单数字号，必须是双数
- 禁止从外部代码复制字体设置

---

## 3. 圆角（Border Radius）

| 用途        | 值    | 说明             |
|-------------|-------|------------------|
| 按钮/输入框 | `6px` | 所有表单控件统一 |
| 卡片/弹窗   | `8px` | 容器类元素       |
| 标签 Tag    | `4px` | 小型元素         |
| 圆形        | `50%` | 头像、圆形按钮   |

**规则：**
- 禁止使用 `2px`、`3px` 等单数非规范圆角

---

## 4. 间距（Spacing）

| 用途           | 值               | 说明                         |
|----------------|------------------|------------------------------|
| 组件内边距     | `8px 12px`       | Input、Select、Button 内边距 |
| 紧凑内边距     | `4px 8px`        | 小尺寸按钮、Tag              |
| 表格单元格     | `12px 16px`      | Table cell padding           |
| 卡片内边距     | `16px` 或 `20px` | 容器内边距                   |
| 元素间距       | `8px`            | 同级元素水平间距             |
| 区块间距       | `16px`           | 不同区块垂直间距             |
| FilterBar 间距 | `12px`           | 筛选项之间的间距             |

## 5. 尺寸（Size）

### 表单控件高度

| 尺寸 | 高度   | 适用场景   |
|------|--------|------------|
| 默认 | `32px` | 大部分场景 |

### 图标尺寸

| 用途       | 尺寸            |
|------------|-----------------|
| 按钮内图标 | `12px`          |
| 导航图标   | `16px`          |
| 空状态图标 | `32px` ~ `48px` |

## 6. 阴影（Shadow）

| 用途     | 值                               | 说明                 |
|----------|----------------------------------|----------------------|
| 下拉菜单 | `0 4px 12px rgba(0, 0, 0, 0.08)` | Select 下拉、Popover |
| 弹窗     | `0 6px 16px rgba(0, 0, 0, 0.08)` | Modal、Drawer        |
| 悬浮卡片 | `0 2px 8px rgba(0, 0, 0, 0.06)`  | 轻量悬浮             |

## 7. 动画（Transition）

| 用途          | 值              |
|---------------|-----------------|
| 颜色/背景过渡 | `all 0.2s ease` |
| 展开/收起     | `all 0.3s ease` |

---

## 8. 通用规则总结

1. **颜色**：只使用本文档定义的色值，禁止随意取色
2. **字号**：默认 12px 不写，标题 14px，禁止单数字号
3. **圆角**：控件 6px、容器 8px、Tag 4px，三档即可
4. **间距**：以 4px 为基数，常用 8/12/16/20
5. **高度**：表单控件默认 32px
6. **边框**：统一 1px solid，色值从边框色表中选取
7. **背景**：输入类控件用 `#f8f9fd`，页面用 `#f8fafc`
8. **状态**：hover 用背景色变化 + 边框色变化，不要用 opacity 变化
