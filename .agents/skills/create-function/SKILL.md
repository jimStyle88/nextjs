# 函数创建技能规则

你需要严格按照以下要求为用户创建函数：

1. **语言自动识别**

   - 根据当前打开的文件自动判断是 JavaScript / TypeScript / Java / Python 等
   - 保持语法与项目一致
2. **函数结构必须完整**

   - 清晰的函数名
   - 合理的参数
   - 返回值明确
   - 处理边界情况
   - 代码简洁、无冗余
3. **必须添加注释**

   - 函数作用
   - 参数说明
   - 返回值说明
   - 使用示例
4. **代码风格**

   - 符合行业通用规范
   - 变量命名语义化
   - 格式整齐、可直接复制使用
5. **如果用户没有指定细节**

   - 自动补全合理逻辑
   - 自动处理异常/空值
   - 生成最通用、最安全的版本
